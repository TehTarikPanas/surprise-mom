## About the Project
Since I couldn’t decide which gift to give, I built this website for her. *Surprise Mom!* is a random gift card site for my mom’s birthday. She can only pick two cards; once selected, the remaining cards are disabled and show an error message.  

**Message For Her:**  
Happy belated birthday, Mom!
May God bless you with good health, peace, prosperity, and many beautiful moments ahead.

---

## Tech Stack
- **Frontend** – HTML, CSS, JavaScript  

---

## Quick Start
To get a local copy up and running, follow these simple steps:

### Prerequisites
- Any modern browser (Chrome, Firefox, Edge, Safari)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/surprise-mom.git
   ```
2. Navigate to the project folder:
   ```bash
   cd surprise-mom
   ```
3. Open `index.html` in your browser.

---

## Usage
- Click on any two cards to reveal surprise messages.
- After two selections, remaining cards are disabled and an error message appears.
- Works seamlessly on desktop and mobile.
